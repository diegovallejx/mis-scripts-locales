# Privacidad de Mis scripts locales

**Responsable:** Diego Vallejos.

Versión de esta política: 10 de octubre de 2026. Código fuente y soporte: https://github.com/diegovallejx/mis-scripts-locales.

El gestor recibe únicamente los archivos de script que la persona selecciona. Conserva su código, nombre, versión, descripción, sitios declarados y estado de activación en el almacenamiento local de la extensión dentro de Chrome. Estos datos se usan para mostrar los scripts y ejecutarlos en los sitios autorizados.

El gestor no tiene cuentas, telemetría, publicidad, análisis de uso, sincronización ni servidores propios. No envía el código importado, el historial de navegación ni el contenido de las páginas a Diego Vallejos ni a terceros. No hay transferencias de datos realizadas por el gestor.

El gestor no almacena el contenido de las páginas que un script lee o muestra. Conserva únicamente el código y los metadatos necesarios para volver a ejecutar los scripts elegidos después de cerrar Chrome. Cada script puede mantener datos temporalmente en la memoria del navegador; su manejo depende de su propio código.

Cuando se activa un script, Chrome solicita permiso para sus sitios. El script se ejecuta en el contexto principal de esas páginas, donde el sitio también puede interactuar con él. **Cada script puede tener su propio comportamiento de red y acceso a datos**, que depende de su código; la persona debe revisarlo antes de activarlo. El gestor no descarga scripts ni sus dependencias.

Los datos copiados por un script pueden permanecer en el portapapeles del sistema hasta que se reemplacen. El gestor no puede controlar los registros, la caché o las copias que mantengan los sitios visitados ni sus servidores.

Los datos permanecen en el perfil local de Chrome hasta que la persona elimina un script, borra los datos de la extensión o desinstala la extensión. Al eliminar un script desde el gestor, se borra su copia local del almacenamiento de la extensión. El archivo original del equipo no se modifica.

Desactivar o eliminar un script impide su ejecución en nuevas cargas de página. Para detener los efectos de un script que ya está funcionando, se debe recargar o cerrar esa página después de desactivarlo. La extensión no puede garantizar el borrado físico inmediato de la memoria o del almacenamiento administrado por Chrome.

Los enlaces de código abierto y privacidad abren GitHub únicamente cuando la persona los pulsa. GitHub y Chrome Web Store aplican sus propias políticas; el gestor no les envía el código importado ni el contenido de las páginas visitadas.

El uso de información recibida mediante las API de Chrome se limita a la función de cargar, revisar y ejecutar los scripts elegidos por la persona, conforme a los requisitos de uso limitado de Chrome Web Store.

Dirección pública de esta política: https://github.com/diegovallejx/mis-scripts-locales/blob/main/PRIVACIDAD.md.
