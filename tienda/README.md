# Material para Chrome Web Store

Las capturas de 1280 × 800 muestran la interfaz real del gestor con el ejemplo público `Resaltar título`. Para generarlas se usaron datos ficticios y se simularon únicamente las API de almacenamiento y permisos de Chrome. No contienen información de usuarios ni páginas privadas.

`promocion-440x280.png` es la imagen promocional. Su fuente vectorial está en `promocion-440x280.svg`.

Estos archivos no se incluyen en el ZIP de ejecución de la extensión.

Las capturas de 0.1.6 incluyen la configuración OTA manual con una fuente de demostración `scripts.example.org`. Las descargas HTTPS se interceptaron en una prueba aislada: el ejemplo público y las versiones de demostración no representan un servidor operativo. Se comprobó que la captura no contiene scripts instalados ni información clínica. La API de Chrome se simuló para la prueba de interfaz; esto no demuestra por sí solo la concesión de permisos en una instalación real.
