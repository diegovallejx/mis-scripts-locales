# Material para Chrome Web Store

Las capturas de 1280 × 800 muestran la interfaz real del gestor con el ejemplo público `Resaltar título`. Para generarlas se usaron datos ficticios y se simularon únicamente las API de almacenamiento y permisos de Chrome. No contienen información de usuarios ni páginas privadas.

`promocion-440x280.png` es la imagen promocional. Su fuente vectorial está en `promocion-440x280.svg`.

Estos archivos no se incluyen en el ZIP de ejecución de la extensión.
